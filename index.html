Cek Peserta Kelas — ITS

myITS Academics · mia.its.ac.id

⚠️ Sebelum pakai — kamu HARUS login MIA dulu

Ekstensi ini memakai sesi login MIA kamu di browser. Jadi syaratnya:

  • Akun mahasiswa ITS yang aktif.
  • Sudah login di mia.its.ac.id di browser yang sama dengan tempat ekstensi dipasang.

Belum login? Nggak masalah — buka tab tool ekstensi → klik tombol “Login di myITS Academics” → login sekali di tab MIA yang terbuka. Ekstensi mendeteksi sesinya otomatis saat kamu kembali ke tab tool.

Setup — pasang ekstensi (sekali saja)
1
Download repo ini (Code → Download ZIP), lalu ekstrak. Siapkan folder extension/.
2
Buka brave://extensions (atau chrome://extensions). Aktifkan Developer mode (pojok kanan atas).
3
Klik Load unpacked → pilih folder extension/. Icon Cek Peserta Kelas — ITS muncul di toolbar.
Pakai — tiap mau cek kelas
1
Pastikan sudah login di mia.its.ac.id (lihat kotak oranye di atas).
2
Klik icon ekstensi → tab tool terbuka.
3
Belum login? Klik “Login di myITS Academics” → login sekali → balik ke tab tool, sesi keambil otomatis.
4
Pilih Semester → Mata Kuliah → Kelas → Lihat Peserta. Tabel peserta tampil & bisa disalin.
Ekstensi membaca sesi login MIA langsung di browser (cookie httpOnly hanya bisa dibaca ekstensi), lalu memanggil API MIA — semua terjadi di browser kamu, tanpa server perantara, tanpa paste cookie. Sesi MIA yang kedaluwarsa tinggal di-refresh lewat tombol login sekali lagi.
